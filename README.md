# Nova AI Assistant

Nova AI Assistant is an intelligent voice-based personal assistant designed to understand user commands, process them using AI, and respond naturally.

## Project Goals

- Voice-based interaction
- AI-powered conversations
- Speech-to-text processing
- Text-to-speech responses
- Useful assistant commands
- Modular and scalable architecture

## Technologies

- Python
- Artificial Intelligence
- Speech Recognition
- Text-to-Speech
- Large Language Model (LLM)
- Git & GitHub
